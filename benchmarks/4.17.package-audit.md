font wanted) or a curl-at-install step (network dependency, unpinned).
Row corrected to state the truth; decision flagged.

## Format bug found on the way (installer-breaking class)

Some rows write `**picked**` (bold) in the Status column; the documented
extraction line matches `$5=="picked"` exactly — **it silently drops the
compositor and terminal rows** (niri, kitty) from any generated package
list. Tonight's audit extraction tolerated both spellings. Fix is one of:
normalize the cells, or widen the documented awk — same shape as the
em-dash question, author's call, flagged in the morning report.
