# Molten and markdown example

> [!TIP]
> **Getting started (BunnE bindings)**
>
> 1. Start the kernel once per session: **`<Space>mi`** (pick `t-jupyter`)
> 2. Put the cursor anywhere inside a ```python fence and press
>    **`<S-Enter>`** — the block runs and its output renders inline below.
> 3. **Reading long output** (errors, tracebacks): `<Space>mo` enters the
>    output window — scroll it like any buffer (`j`/`k`, `Ctrl+d`/`u`) —
>    then **`q`** returns to the document.
> 4. `<Space>mh` hides a cell's output, `<Space>ms` shows it again.
> 5. `;l` is Esc, as everywhere.
>
> Notes: images and plots need kitty (a warning fires if not). Plot math
> like `$\pi^2$` renders via matplotlib's built-in mathtext — no LaTeX
> install; `text.usetex` will fail unless texlive is ever installed.

# Matplotlib example

```python
import numpy as np
import matplotlib.pyplot as plt
import matplotlib

matplotlib.rcParams['figure.dpi'] = 150
plt.style.use('dark_background')


data = [np.pi ** 2 / 6.0 - sum([1.0 / (i * i) for i in range(1, n)]) for n in range(1, 20)]
fig, ax = plt.subplots()
fig.patch.set_facecolor('#00000000')
ax.patch.set_facecolor('#00000000')
ax.set_xlabel(r'$N$')
ax.set_ylabel(r'$S_N$')
ax.set_title(r'$S_N \equiv \frac{\pi^2}{6} - \sum_{k=1}^{N} \frac{1}{k^2}$')
img = ax.plot(data, color = 'white')
img = ax.plot(data, 'o', color = 'white')
```
