# 4.13 — external display: the hybrid-graphics hard case (Arch half)

`arch-bunny`, 2026-08-24, author present and monitor physically attached
(AOC 2279WH on HDMI-A-1). The non-negotiable from resume.md: external ports
are wired to the NVIDIA card, so a docked session is a genuine multi-GPU
Wayland session.

Evidence (compositor + kernel state, this session):

- `card0-HDMI-A-1: connected` (card0 = NVIDIA), `card1-eDP-1: connected`
  (Intel panel) — the two outputs live on different GPUs.
- niri drives both: AOC at 1920x1080@60 preferred mode, extended desktop at
  logical (1920,0); full mode list enumerated.
- **A real kitty window was moved onto the NVIDIA-driven output**
  (workspace 2 = HDMI-A-1, focused) via niri IPC — cross-GPU window
  management works.
- **dGPU cost of scanout: ~nil at idle** — nvidia-smi read P8 / 9.49-9.63 W
  / 0% util *while scanning out 1080p60*, vs 9.25 W with no display
  attached earlier the same day. Driving the external display does not wake
  the card out of P8.
- Author's visual confirmation of the pixels: requested, recorded when
  given.

NixOS half: same session, after the flip — its ledger predicted the docked
case needs PRIME reverseSync (its GPU row chose offload); whether niri's
native multi-GPU handling makes that X11-era distinction moot is exactly
